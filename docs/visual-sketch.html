1. 运行任务自适应阈值规则 (Adaptive Task Threshold)

  • Count ≤ 3 (常规并发)：在主菜单顶部采用紧凑内联条目直接展示，每行占用 26px，高亮显示微型旋转环和停止按钮。
  • Count > 3 (高负载/批处理)：主菜单顶部仅占用单行 正在运行的任务 (N) ▶。鼠标悬停时右滑弹出二级子菜单，容纳完整的任务列表并提供“全部终止”选项。
  • 设计动机：彻底避免菜单被临时任务占满，保障正常快捷指令的一键访问视线不被破坏。

2. SF Symbols 与无文本按钮 (Icon-Only Destructive Action)

  • 消除中文赘字：去除破坏紧凑排版的“⏹ 停止”文字，直接使用 stop.circle.fill 或 stop.fill。
  • 视觉层次：平时保持 opacity: 0.75，不喧宾夺主；当鼠标 Hover 时呈现 rgba(255, 69, 58, 0.15) 危险色圆形微背景与放大微反馈。
  • 无障碍与无歧义：通过 accessibilityLabel("终止快捷指令: [Name]") 和 Tooltip 满足系统无障碍要求。

3. 菜单栏图标与 CoreAnimation 旋转 (ScriptMonitor)

  • 图标形态：严守 18×18 pt 模板图 (Template Image)，自动适应浅色/深色菜单栏。
  • 环形进度：使用 CAShapeLayer 绘制极细线宽（1.5pt）的平滑旋转圆环，多任务时挂载数字徽标，单任务完成后微闪绿色 1.2s 平滑淡出。
